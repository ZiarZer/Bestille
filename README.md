# Bestille
#### A Spigot plugin adding a friendship level between players

### Features
Every 10 seconds, all alive players will gain 1 friendship level with other players near them (in a 100m radius).\
\
To know how good friends you are with another player, use the `/friendship <player>` command.\
To see all your friendships, use the `/friends` command.

**_Admins only_**\
You can see all the friendship levels of a player with the `/seefriendship <player>`.\
You can see the friendship level between two players with the `/seefriendship <player1> <player2>` command.
